# MacroInvest Edu / Macro-Sim — Static MVP (Educational)

This is a static, ready-to-open multi-page website prototype for the MacroInvest Edu / Macro-Sim concept:
- Public pages: Home, Programs, Simulators, Methodology (versions + data dictionary), Impact, FAQ, Documents
- Demo "app" pages: Dashboard and Labs
- Interactive Macro→Portfolio Lab: deterministic educational simulation + scoring + JSON/TXT export and scenario comparison.

## How to run
Open `index.html` in a browser (double-click), or serve the folder with any static server:
- Python: `python3 -m http.server 8000` and open http://localhost:8000

## Notes
- This demo does NOT provide investment recommendations.
- Portfolio Lab metrics are stylized, deterministic, and educational. Replace with server-side model service + real data pipeline for production.
